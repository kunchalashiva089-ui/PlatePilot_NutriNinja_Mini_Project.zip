PLATEPILOT FRONTEND

1. Extract the ZIP file.
2. Open the PlatePilot_Frontend folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Enter a budget, diet preference and fitness goal.
5. Click "Generate my plan". Try the Swap and Save plan buttons.

Files:
- index.html: page structure and Chart.js import
- style.css: responsive styling
- app.js: sample recipes, budget-aware meal selection, swaps, chart and LocalStorage

This is a frontend prototype. It uses a small sample recipe dataset and estimated prices/macros.
Chart.js is loaded from a CDN, so an internet connection is needed for the chart.
No backend is included.
